# edzaputil-HW9
BAIS:3300 Module 9 Homework - creating web form

**Project Description**  
This project is a two-page web form designed to collect information from Business Analytics students about their background and experiences. The forms uses HTML5, CSS, and Bootstrap 5.3 to create a responsive, user-friendly, and accessible design

**Best Practices for Web Forms**  
This web form was developed using several best practices to ensure clarity, usability, and efficiency for user. Each input field is labeled and grouped logically using fieldset and legend elecments, helping users understand how the options relate to each other. Required fields are marked using the required attribute to ensure essential data is collected without confusion or incomplete submissions. Additionally, appropiate input types such as text, select, radio buttons, and checkboxes are used to match the data being collected, improving accuracy and reducing user error.

The form also uses Bootstrap's responsive grid and utility classes to maintain consistent spacing, alignment, and readability across devices. Buttons and form controls have sufficient padding and visual contrast to make them easily clickable and distinguishable. The "Next" button is placed at the bottom of the form, following a natural flow, and uses the "type = submit" attribute to ensure proper validation before proceeding to the next page.

Clear feedback and instructions are integrated. For example, tooltips are used to provide guidance to users when additional explaination is necessary. These design choices contribute to a positive and efficient user experience that adheres to web form usability standards.

**Accessibility Considerations**    
Accessibility was prioritized throughout the form's design to ensure all users, including those using assistive technologies, can complete it easily. Each input field includes a label with the for attribute properly linked to its input, which improves navigation for screen readers. The form also follows a logical order and uses semantic HTML element like form, fieldset, legend, and label to enhance structure and accessibility.

Bootstrap's built-in accessibility support, along with color contrast and large clickable areas ensures that users with visual or motor impairments can interact with the form effectively. Tooltips and icons include accessible text descriptions to provide context for users who rely on screen readers.
